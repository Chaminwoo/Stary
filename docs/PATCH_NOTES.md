### 자세히

**별 도감(신규 메뉴, 드로어 "내 다이어리" 바로 아래)**
- 100m 접근 또는 광고로 해금한 **다른 사람의** 별을 화면 중앙 원 위에 모아 본다. 들어가면 12시 방향부터
  시계 방향으로 별이 하나씩 빠르게 떠올라 약 1.5초 만에 원이 완성된다.
- 화면을 누른 채로 별 위를 지나가면 그 별이 커지고, 원 가운데에 제목·작성자·해금 시점·거리·"지도에서 보기"가 뜬다(손을 떼도 유지).
  글씨는 그 별의 색을 따르고 후광이 비친다. "지도에서 보기"를 누르면 지도로 돌아가 그 별 위치로 카메라가 이동한다.
- 정렬(해금순/최신순/거리순/인기순), 필터(친구만/친구 선택)를 지원한다.
- 광고로 해금한 다이어리는 **별 도감에 영구히 남는다** — 안내 문구 추가.

**지도 필터 — 별이 하나 둘 나타나는 연출**
- 필터를 바꾸면(미조회만/해금만/친구만/나만보기/친구선택/기간별) 화면 안의 별이 무작위 순서로 하나씩
  "톡" 떠오른다(약 1.3초 안에 완료). 별이 뜨는 순간마다 은은한 반짝임 효과음이 함께 난다.

**별자리 — 선이 별에서 별로 흐르듯 연결**
- 별자리 버튼을 누르면 화면 중앙에 가까운 별에서 출발해 선이 별과 별 사이를 타고 자라나며,
  선이 새 별에 닿는 순간 작은 빛이 번진다. 끌 때는 기존처럼 부드럽게 사라진다.

**효과음 4종(신규)**
- 별이 하나 둘 떠오를 때(지도 필터·별 도감), 다이어리 업로드 성공 시 별이 탄생할 때, 좋아요를 눌렀을 때,
  드로어(메뉴)를 열 때 — 각각에 맞는 짧은 효과음을 넣었다. 소리 크기는 설정의 효과음 볼륨을 그대로 따른다.

**언어 전환**
- 설정에서 언어를 바꿔도 한국어로만 나오던 문제를 고쳤다. 스토어에서 받은 앱이 기기 언어에 맞는
  번역만 담고 있어 벌어진 문제로, 이제 모든 언어가 항상 함께 설치된다.

**지도 카메라 유지**
- 지도에서 별(다이어리)을 눌러 상세로 들어갔다가 뒤로가기로 돌아오면, 예전엔 항상 내 위치로 카메라가
  이동했지만 이제는 **보던 자리 그대로** 남는다. 드로어 메뉴·알림·업로드 화면에서 돌아올 때는 기존처럼 내 위치로.

**잠금 화면 문구**
- "광고를 통해 열어보세요!" → **"광고를 통해 해금하세요!"** 로 문구를 다듬었다.

**결정(다이아몬드) 별 모양**
- 모양 안쪽에 보이던 가는 검은 선을 없애고, 대신 파편(컷 면) 무늬를 더 촘촘하게 넣어
  검은 선 없이도 컷 다이아몬드 느낌이 나게 했다.

**새 버전 안내**
- 앱을 열었을 때 스토어에 더 새 버전이 올라와 있으면 안내 팝업이 뜬다. "업데이트하러 가기"를 누르면
  바로 스토어 페이지로 이동한다.

**프로필 화면**
- 떠다니는 아이콘끼리 부딪히면 효과음이 난다.
- 드로어(≡) 메뉴를 열면 항목이 위에서부터 하나씩 스르륵 나타난다.

### 사용자에게 보이지 않는 변경
- 언어 전환 원인: Play 앱 번들(AAB) 의 언어 분할 — `enableSplit = false` 로 전 언어를 항상 포함시킴.
- 다이어리 저장/수정/삭제·친구 요청 등 토스트 문구를 하드코딩 문자열 대신 리소스/enum 으로(비교 로직에도 문자열을 안 쓰게).
- CLAUDE.md 에 언어 전환 재발 방지 체크리스트 추가(3번째 재발이라 원인·확인 순서를 문서화).
- 효과음은 외부 음원 없이 코드로 직접 합성(`tools/sfx/`) — 저작권 문제 없음.

### 자세히

**잠긴 게시물(100m 밖) 화면**
- 잠긴 사진·영상 자리: 가운데 자물쇠 + 화면 35% 어둡게를 **삭제**하고, 우하단에 "이 사진/영상은 잠겨 있어요" 캡션만 조용히 남겼다.
  미디어가 없는 글은 잠금 표시 없이 평소와 같은 배경.
- 본문 자리: **재생 아이콘 하나**가 곧 버튼이다(기존 "광고 보고 열람하기" 버튼 삭제). 탭 = 보상형 광고.
  잡아당기면 고무줄처럼 버티다 놓으면 출렁이며 제자리로 돌아온다.
- 안내 문구: "100m 이내로 다가가거나, 광고를 통해 열어보세요!" + **현재 위치로부터의 거리**(실시간).
- 영역 표시가 카드(배경+둥근 테두리)에서 **좌상단·우하단 십자 코너 프레임**으로 바뀌었다.
  **해금한 뒤의 본문도 같은 프레임**이라 열기 전후 화면이 끊기지 않는다(1.4.4 에서 마지막으로 맞춘 부분).

**영구 해금**
- 광고를 끝까지 봤거나 **100m 안에 한 번이라도 들어온** 게시물은 기록이 남아, 이후 멀어져도 계속 열람할 수 있다.
  (기존 7일 후 다시 잠김 → **영구**. 기존 해금 기록은 그대로 승계된다.)
- 단 **댓글 작성만은 항상 100m 이내**여야 한다 — 내 글도 마찬가지. 밖에서는 입력창이 잠기고 안내가 뜬다.

**별 모양**
- 결정(다이아몬드) 별을 더 작게(0.66 → 0.56) + 중심에서 아래로 내려가던 **세로선 제거** — 💎 아이콘에 가까운 형태.

**광고**
- 보상형 광고를 Unity Ads 직접 연동 → **Unity LevelPlay 미디에이션**으로 교체(Unity 의 직접 연동 수익화 지원 종료 대응).
- 광고를 받지 못할 때를 위한 **대체 경로(폴백)** 추가 — 아이콘을 눌렀는데 아무 반응이 없는 상황을 줄였다.
- 아직 불러오는 중이면 "광고를 불러오는 중이에요" 안내 후 도착하는 즉시 재생.

**지도 필터 "해금만"**
- 잠금 없이 바로 열리는 별만 남긴다 — **내 글 / 이미 해금한 별 / 지금 100m 이내**(상세 화면의 해금 규칙과 동일).
  즉 이 필터로 보이는 별은 눌러도 잠금 화면이 뜨지 않는다.
- "미조회만"과는 상호배타(해금은 상세에 들어가야 기록되므로 같이 켜면 항상 빈 지도).

**본문 읽기 편의**
- 해금된 긴 본문이 순흑 배경 위에서 번져 보이던 것을 보완 — 카드를 되살리지 않고 **테두리 없는 옅은 읽기 면**을 깔고
  행간(26→28)·줄바꿈(한글 어절 단위)·글자 밝기를 다듬었다. 십자 코너 형식은 그대로.
- 튜토리얼 별 화면도 상세 화면과 같은 형식으로 맞췄다.

**일일 알림**
