| `app-screens/en-ui_1206x2622/` | 위 화면의 UI 문구를 영어로 교체한 버전 | 1206×2622 |

참고
- 슬라이드/듀오의 폰 하단은 원본이 잘려 있어 합성한 부분이 있다(실제 앱 화면 아님). 제출 전 실제 캡처로 교체 권장.
- 영어 UI 화면은 문구를 임의 번역/로마자 표기해 덧씌운 것이다(프로필 이름 포함).
- `slides-1206x2622/en` 의 폰 내부 UI 는 한국어 그대로다.
