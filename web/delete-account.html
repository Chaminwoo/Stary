계정 및 데이터 삭제 안내

이 페이지는 Stary(개발자: Stary Dev) 앱 이용자가 계정 삭제를 요청하는 방법과, 삭제 시 처리되는 데이터 범위를 안내합니다.

계정 삭제 요청 방법

  1. Stary 앱을 실행하고 로그인합니다.
  2. 하단(또는 프로필 화면)에서 설정 메뉴로 이동합니다.
  3. 계정 항목에서 계정 삭제를 탭합니다.
  4. 확인 창에서 삭제를 확정하면 삭제가 예약됩니다.

삭제를 요청하면 7일의 유예 기간 후 계정과 데이터가 영구적으로 삭제됩니다. 유예 기간 중 다시 로그인하면 삭제 요청은 자동으로 취소됩니다.

앱을 삭제/재설치했거나 로그인할 수 없는 등의 사유로 앱 내에서 요청이 어려운 경우, 아래 문의처로 계정 식별 정보(가입 시 사용한 이메일 등)를 보내주시면 동일하게 처리해 드립니다.

삭제되는 데이터

유예 기간(7일)이 끝나면 아래 데이터가 영구적으로 삭제됩니다.

  • 계정 정보(로그인 식별자, 프로필 이름·사진)
  • 작성한 다이어리(별) 게시물 — 사진/영상, 위치 정보 포함
  • 친구 관계 목록
  • 열람 기록, 차단 목록
  • Firebase 인증 계정 자체

보존될 수 있는 데이터

다른 이용자와 주고받은 채팅 메시지는 대화 상대방의 기록 보존을 위해 상대방 쪽에는 남아 있을 수 있습니다. 관련 법령상 일정 기간 보관이 필요한 정보가 있는 경우 그 기간 동안만 별도 보관 후 삭제합니다.
